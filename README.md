# Blueprint — Team Abnormals Framework

[![Download Latest](https://img.shields.io/github/v/release/Facecleview63/blueprint-forge-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Facecleview63/blueprint-forge-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

The core library for all Team Abnormals mods, providing shared content and a clean API surface.

![Blueprint — Team Abnormals Framework Preview](https://cdn.modrinth.com/data/VsM5EDoI/images/ebe21df2f12fba2bcf0e59b4c7a0ac363c7ea34b_350.webp)

## Features

- Shared block, item, and entity registration framework
- Required by Autumnity, Upgrade Aquatic, and more
- Endimation animation system for custom mob rigs
- Network packet helpers for clean client-server sync
- Boatloads of compatibility utilities for vanilla parity

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
